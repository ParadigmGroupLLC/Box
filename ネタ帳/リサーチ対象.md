# リサーチ対象

trend-researcher が、ここに書いたアカウントとキーワードから候補を探します。

## 見るアカウント
自分と近いジャンル（カフェ・コーヒー・朝の過ごし方など）で、リールが伸びているアカウントを書きます。
URLは、実際に開けることを確かめてから書いてください。

| アカウント | URL | ジャンル | 見る理由 |
|---|---|---|---|
| （例）@xxxx | https://www.instagram.com/xxxx/ | 個人カフェ | 新作紹介の型が近い |
|  |  |  |  |
|  |  |  |  |

## 検索キーワード
アカウントから候補が足りないときだけ使います。

- コーヒー 淹れ方
- 自宅コーヒー
- カフェ 新作
- モーニング カフェ
- 朝活 カフェ
- 出勤前 カフェ
- コーヒーのある暮らし

## 見ないもの
- テーマが「こもれびコーヒー」と合わないもの（お酒・夜カフェ・遠方の観光地など）
- 数字が見えないもの
