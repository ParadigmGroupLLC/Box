## 3. わかったこと（まとめ）
1. **「あるある」は、業界全体でも一番反応が多い型。** 成豊建設で伸びた「99%共感」「言わないこと」と同じです。続ける価値があります。
2. **トンネルなら「機械」「昔の写真」「貫通」「SFっぽい現場」「飯場の食事」が好まれる。** 先日の台本7本（①自動化・③SF・⑤貫通式・⑥歴史）は、この流れに合っています。
3. **人が立つと強い。** 同じ人が毎回出てくるアカウントが上位に多いです。採用担当のキャラをもっと前に出せます。
4. **若手の節目は、若い人への入口になる。** 入社式・内定式・資格試験は、毎年決まった時期に撮れます。

## 4. 新しい企画の案（台本7本に足すもの）
| 案 | 中身 | 理由 |
|---|---|---|
| A. 施工管理あるある（寸劇シリーズ） | 「施工管理が朝イチでやること」「現場で一番うれしい瞬間」などを、社員の寸劇で。毎回同じ採用担当が出る | 業界で一番反応が多い型。キャラも立つ |
| B. トンネルの機械図鑑 | 1本1台。「これ何でしょう？」→名前→何をする機械か（ドリルジャンボ・吹付ロボット・セントルなど） | トンネルの投稿で一番多い型。シリーズにしやすい |
| C. 飯場飯・現場めし | 現場の食事や、宿舎での食事を毎週1本 | Instagram でも続けて投稿されている。成豊建設の「食堂飯」は TikTok で強かった |
| D. 若手の節目 | 内定式・入社式・資格試験の前日と合格発表 | 若い人への入口。毎年同じ時期に撮れる |
| E. 昔と今の写真くらべ | 昭和の現場写真と、今の同じ作業を並べる | 「昔の写真」が好まれる。⑥歴史の続きにできる |

## 6. 追加の企画案（2026-11-04、「他にも考えて」への答え）

成豊建設で伸びた投稿の傾向と、上の調べた結果を元にしています。

| 案 | 中身 | 理由（根拠） |
|---|---|---|
| F. 昭和 vs 令和の現場 | 同じ場面を「昭和の現場」と「令和の現場」で2回見せる寸劇。例：朝礼・休けい・新人への教え方 | 「昔の風習」は12.4万回でアカウント最高。表示名も「たまに昭和が漏れる採用担当」で、キャラと合う |
| G. トンネル用語「これ読める？」 | 「切羽」「坑口」「覆工」「ずり」などを画面に出し、3秒待ってから読み方と意味 | 答えを考えさせると最後まで見られやすい。コメント（答え合わせ）も集まりやすい |
| H. 現場の道具・機械 当てクイズ | 道具や機械の一部をアップで見せ「これ何？」→引きで答え | トンネルの投稿では機械の写真が上位に多い。B（機械図鑑）の入口にもなる |
| I. 入社前のイメージ vs 実際 | 画面を左右に分け、若手が「思っていたこと」と「実際」を並べる（インタビューにしない） | 若手が主役の投稿は、ネタの形なら伸びる（配属1年目・ズレてる若手） |
| J. 個室宿舎ツアー | 現場の宿舎の部屋を30秒で見せる | プロフィールとキャプションに「個室宿舎」があり、暮らしの話は TikTok で強い（食堂飯） |
| K. 施工管理のカバンの中身 | 現場に持っていく物を1つずつ出す | 持ち物紹介は短く作りやすく、仕事の中身が自然に伝わる |
| L. 「1日」シリーズの職種ちがい | 測量・機械・事務など、職種ごとの1日を各30秒で | 「トンネル施工管理の1日」は Instagram と TikTok の両方で約1.4万回。同じ型を続けられる |
| M. 日本中の現場めぐり | 地図に現場の場所を点で出し、各地の景色を1秒ずつ（工事名・地名は出さない） | 決まり文句「日本中に、成豊建設の仕事がある。」をそのまま映像にできる |

**先方に確かめたいこと**
- F・I・K：出てもらえる社員（とくに若手）がいるか。
- J：宿舎の部屋を撮ってよいか。
- M：現場の場所を、地図の点として出してよいか（工事名・地名は出さない）。
- G・H：使う用語や機械が、成豊建設の現場で使っているものか。

**おすすめ**：F（昭和 vs 令和）と G（用語クイズ）は、撮るものが少なく、すぐ作れます。
