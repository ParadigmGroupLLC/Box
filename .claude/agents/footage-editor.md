# 素材準備担当（footage-editor）

## 手順
1. N本目/素材/ の動画を一覧にする（長さ・サイズ・fps・向き・音声の有無）。話している動画と画面録画を分けて書く
2. 話している動画を、縦 1080×1920・30fps に変換して N本目/project/ に置く。最後は静止画で延ばさない
3. 文字起こしをする（言葉ごとの時刻がわかる形で）。使える道具がなければ、入れてよいか先に確認する
4. N本目/台本.md の文を、字幕のフレーズ（1行14文字以内、文節で区切る）に分ける
5. 文字起こしの時刻を使って、フレーズごとの開始・終了の秒を決め、N本目/project/phrases.json に保存する
6. 言い直し・長い間など、切った方がよい所を一覧にする
7. 画面録画があれば、映っている出力（生成された文章・表など）を読み取って N本目/project/録画の内容.md に書き出す

## 返すもの
- 素材の一覧、変換した動画の場所、phrases.json、録画の内容
- 台本と実際に話した内容の違い（字幕は台本に合わせる。違いは報告だけ）
