# @zensin_grp 投稿の概要欄に毎回載せる文（固定キャプション案、2026-11-05）

依頼：オフィスのチャット（2026-11-05、宛先：チーム全体）「ZENSINのアカウントの投稿の概要欄に固定で載せる内容を考えてほしい。どんなアカウントのジャンルなのかを認知してモラルないようで考えて」

## 前提
- アカウントのジャンル：目標達成に向けたモチベーション・マインドセットのリール（10/29 のプロフィールより：「Japan | Mindset | Motivation」「毎日のやる気を上げるリールを投稿中」、TikTok @zensin_motivation）。
- 投稿の中身と最新の数字は、Supermetrics の Instagram の接続が切れているため見ていません。
- 「モラルある内容」を、次の4つと受け取りました。
  1. 誇張しない（「必ず成功する」「人生が変わる」などと約束しない）
  2. 人を否定しない（「努力しない人はダメ」のような言い方をしない）
  3. 無理をあおらない（休むことも大事だと伝える）
  4. 人の言葉を使うときは、だれの言葉かを書く

## 使い方
- 投稿ごとに変えるのは、1行目の【　】だけです。2行目から下は、毎回そのまま貼ります。
- ハッシュタグは5つまでにしています（つけすぎると、関係のない人に届きやすくなるため）。

```
ZENSIN は、やる気が戻る言葉とリールを届けるアカウントです。

📌 保存して、くじけそうな日に見返してください
💬 今日の小さな一歩を、コメントで教えてください
👉 フォローすると、次の言葉も届きます

焦らなくて大丈夫。休むことも、前に進むための時間です。
引用した言葉は、話した人の名前を書いています。

#モチベーション #マインドセット #目標達成 #自己成長 #前向きな言葉
```

## 足すかどうか決めてほしい行
- **相談先の一言**：重い気持ちに触れる投稿（「つらい時に」など）のときだけ、最後に足す案です。
  ```
  つらい気持ちが続くときは、ひとりで抱えず、身近な人や専門の相談窓口に頼ってください。
  ```
  - 窓口の名前（厚生労働省の「まもろうよ こころ」など）を入れる場合は、【要確認】最新の案内を確かめてから入れます。

## 【要確認】
- 「ZENSIN」は「前進」の意味ですか？ そうなら案A・Cの「休むことも前進です」が、名前とつながります。
- 案C の「毎日」：毎日投稿していない場合は「毎日」を外します（確かめていないことは書かないため）。
- 人の言葉（名言）を使う投稿があるか。ある場合は、話した人の名前を1行目の【　】に入れます。
