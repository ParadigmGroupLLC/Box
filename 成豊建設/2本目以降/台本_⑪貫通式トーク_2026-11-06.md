# 成豊建設 台本：貫通式の動画を見ながら、人事の2人でトーク（⑪、2026-11-06）

依頼：オフィスのチャット（宛先：チーム全体）「建設会社の貫通式の動画を見ながら２人がトークするリールを撮りたいんだけど、構成と内容考えて」。
追加の依頼（報告欄から）：「人事の２人が出演して、１人は現場経験者、１人は現場経験なし」→ 職長と若手から、人事の2人に書き直しました。

## 構成（画面の割り方）

```
┌────────────────┐
│（上の端：大事な文字を置かない）│
│                │
│   貫通式の動画（上半分）   │
│                │
├── 字幕（境目に置く）──┤
│                │
│  人事の2人が見ている（下半分）│
│                │
│（下の端：大事な文字を置かない）│
└────────────────┘
```

- 0秒目は、いちばん見たい場面（最後の壁が開き、光が入る）から始める。
- 見どころは3つ（壁を開ける・握手・鏡開き）。現場未経験の人事（B）が聞いて、現場経験のある人事（A）が答える。
- 最後はAの本当の思い出と、人事としての一言「この景色、一緒に見る人を探しています」で締める。
- 使う動画は成豊建設の貫通式のものだけ（ほかの会社の動画は使わない。チームの決まり）。

## 台本：貫通式の動画を見ながら、人事の2人でトーク

- 企画（依頼のまま）：建設会社の貫通式の動画を見ながら、2人がトークするリール（2026-11-06 の依頼）。出演は人事の2人：1人は現場経験あり、1人は現場経験なし（同日の追加の依頼）
- 型：画面を上下に分ける（上：貫通式の動画／下：見ている人事の2人）。答え（いちばん見たい場面から）→ 何の式？ → 見どころ×3（未経験の人が聞き、経験者が答える）→ 経験者の思い出 → 人事としての一言 → CTA
- 長さの目安：約30秒 ／ 字幕の文字数：189字（本人の一言を除く）／ ビート数：8

### 撮影メモ

- 貫通式の動画は、成豊建設の現場で撮ったものだけを使う（ほかの会社の動画は使わない。チームの決まり）。【要確認：成豊建設の貫通式の動画があるか】
- 画面の割り方：上半分に貫通式の動画、下半分に人事の2人。字幕は上と下の境目に置き、2人の顔に被せない。画面の上の端と下の端には大事な文字を置かない。
- A＝現場経験のある人事、B＝現場経験のない人事。Bは見る人と同じ目線で素直に聞き、Aは自分の経験で答える。字幕の「A：」「B：」は、2人の名前に替えてもよい。
- Bには撮るまで動画を見せず、初めて見る反応をそのまま撮る。台本の言葉は流れの目安で、2人の言葉に差し替える。
- 撮り方：2人の前にタブレットで動画を流し、2人を正面から撮る。動画の画面も別に撮っておくと、編集で上下に並べやすい。
- 上の動画の音は小さくし、2人の声を聞こえるようにする。BGM は動画に入れず、投稿するときに Instagram で付ける。
- 発破の場面は使わない。工事名の看板・地名・発注者や他社の人の顔がわかる場面は、ぼかすか別の場面にする。

### 【要確認】

1. 成豊建設の貫通式の動画があるか。あれば、どの現場のものか（工事名を出してよいか）。
2. 動画の中で、①壁を開ける ②真ん中で握手 ③鏡開き、の3つが映っているか。違う場面があれば、見どころを入れ替える。
3. A（現場経験のある人事）が、貫通式に出たことがあるか。なければ#6を「現場で一番うれしかったことは？」に替える。
4. #6のAの答えは、本人に聞いてそのまま使う。作った気持ちを言わせない。
5. 2人の名前と肩書きの出し方（「人事（元・現場）」でよいか）。
