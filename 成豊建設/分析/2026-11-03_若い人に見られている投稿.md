# @seihoh_kensetsu 若い人（10代・20代）に見られている投稿と傾向（2026-11-03）

データ：Supermetrics の Instagram Insights と TikTok Organic（2026-11-02 取得）。スキップ率は 2026-11-02 に保存した値。
前の分析：成豊建設/分析/2026-11-02_アカウント分析.md、成豊建設/分析/2026-11-02_TikTok分析.md

## 1. 先に大事なこと：「投稿ごとに何歳の人が見たか」は取れません

- **Instagram**：年齢がわかるのは「フォロワー全体」だけです。投稿ごとの年齢は、Supermetrics の数字に出てきません。
- **TikTok**：年齢のデータそのものが取れません（取れるのは性別と国だけ）。
- そのため「若い人が一番見ている投稿」を、数字で直接言うことはできません。
- 代わりに、**若手社員が主役の投稿**（若手・新入社員・配属1年目）がどう見られているかを比べました。若い人に向けた投稿の、いちばん近い目安です。

## 4. 傾向

1. **若手を「あるある・ネタ」で見せる投稿が、両方の SNS で一番見られています。** 「配属1年目」「ズレてる若手社員」は、Instagram でも TikTok でも中央値の約2〜3倍です。
2. **インタビュー・紹介の形は、両方で一番見られていません。** スキップ率が60%を超え、最初の1〜2秒で半分以上の人が離れています。
3. **伸びた2本は短いです。** TikTok で25〜32秒。最後まで見た人も16〜26%と高めです。60秒を超える若手の投稿は、最後まで見た人が3〜6%です。
4. **「若手」というテーマだけでは伸びません。** 若手の投稿7本の再生数の中央値は、Instagram 1,606回（ほかの投稿と同じくらい）、TikTok 1,585回（ほかの投稿 2,244回より少ない）。**伸びるかどうかは、テーマより形（ネタか、インタビューか）と長さで決まっています。**

## 5. おすすめ

- 若い人に届けたい投稿は、**「配属1年目の〇〇」「若手あるある」のようなネタの形で、30秒以内**にする。
- インタビューで伝えたい内容（仕事のやりがいなど）も、「〇〇が絶対に言わないこと」のようなネタの形に作り直す。
- 投稿ごとの年齢を本当に確かめたいときは、Instagram と TikTok のアプリで、投稿ごとのインサイトに年齢が出ているか確認してください。出ていれば、その画面のスクリーンショットをもらえれば集計します（自動で画面を読み取ることはしません）。

## 6. まだわからないこと
- 投稿ごとに、何歳の人が見たか（どちらの SNS も Supermetrics では取れません）。
- 10代がどれくらい見ているか（Instagram のフォロワーのデータにも出てきません）。
- 若手の投稿でフォローした人が若い人か（フォローした人の年齢は取れません）。

## 追記：プロフィールのリンクのクリック数と年齢（2026-11-03）

- **クリックした人の年齢は、Instagram も TikTok も取れません。**
- **Instagram のリンクのクリック数**
  - アカウント全体の「リンクのタップ数」は、直近30日・90日とも数字が返ってきませんでした。
  - 投稿ごとの「プロフィールのリンクのクリック」は、通常の投稿（フィード）にしか出ません。5/23 のアカウント紹介の投稿で4回です。リール33本は、どれも数字が出ません。
- **TikTok**：リンクのクリック数は取れません。取れるのはプロフィールが見られた回数で、10/4〜11/1 の29日で 1,312回でした。
  - 多かった日：10/17（1日密着を投稿）225回、10/22（重機）107回、10/10（99%共感）90回、10/29（配属1年目）80回。
  - 1日密着は TikTok でフォローは少なかったものの（その日+4人）、プロフィールを見に来た人はいちばん多い日でした。
- **クリック数を測るには**：プロフィールのリンクの先（公式LINE や採用サイト）の数字を見るのが確実です。
  - 公式LINE の友だち追加数。
  - 採用サイトに Google アナリティクスが入っていれば、Instagram・TikTok から来た人の数。
  - 年齢は、Google アナリティクスの設定によっては見られる場合があります（確かめていません）。
